# 画面の決まりごと（デザイン指針）

このシステムの実体は**出勤簿・賃金台帳といった帳簿**です。画面もそう見えるように揃えます。
罫線は細く強く、数字は桁をそろえ、行はゆったり。色はクラブの緑ひとつに絞ります。

トークンは `src/index.css` の `@theme`、共通部品は `src/components/UI.tsx` にあります。
**この2つが正**で、画面側は原則そこから借りるだけにします。

## 色

| トークン | 用途 |
|---|---|
| `ink` / `ink-soft` / `ink-mute` | 本文 / 補助 / 注記・プレースホルダ |
| `pine` / `pine-dark` / `pine-soft` | クラブの緑。主ボタン、選択中、承認済 |
| `paper` | ページの地。表の見出し背景 |
| `rule` / `rule-soft` | 表の上下・見出しの罫 / 行間の細い罫 |
| `alert` / `alert-soft` | 誤り、削除、休日 |
| `caution` / `caution-soft` | 未承認・申請中・注意 |
| `info` / `info-soft` | 補足の案内 |

使い方の決まり：

- **色は意味を持つときだけ使う。** 装飾で色をつけない。
- `blue-*` `gray-*` `emerald-*` などの素の Tailwind 色は**使わない**。上のトークンに置き換える。
  - 例外：カレンダーの曜日色（日曜=`text-alert`、土曜=`text-info`）のように、
    もともと意味を持っている色はトークンに寄せたうえで残す。
- 状態の色は全画面で共通にする。

| 状態 | 色 |
|---|---|
| 承認済・完了・残あり | `pine`（Badge の `green`） |
| 申請中・未承認・期限注意 | `caution`（Badge の `yellow`） |
| 却下・休日・不足 | `alert`（Badge の `red`） |
| 未定・対象外 | `ink-mute`（Badge の `gray`） |

## 文字

- 本文 `text-sm`（14px）。ページ見出しは `PageContainer` の `title` に任せる。
- **`text-[10px]` や `text-[11px]` は使わない。**最小は `text-xs`（12px）。
  これまで補足を 10px で書いていた箇所が多いので、`text-xs text-ink-mute` に直す。
- 太字は `font-bold` か `font-medium` の2段階まで。
- 英数字の装飾（全部大文字、字間を広げる等）はしない。

## 数字

**時刻・時間数・金額・日数のセルには必ず桁そろえを効かせる。**

- 表のセル：`<Td numeric>` を使う（右寄せ＋`tabular-nums` が入る）。見出しも `<Th numeric>`。
- 表以外：`className="num"` を足す。
- `Input` は `type` が number/time/date/month のとき自動で桁がそろう。

## 間隔と大きさ

- カードの内側は `p-5`。カード同士は `mb-4`。
- 表の行は `Td`/`Th` の既定（`py-2.5`）のまま。詰めない。
- ボタンは既定 `size="md"`（`py-2.5`）。**職員側の主要な操作は `size="lg"`。**
  指で押す場所を `size="sm"` にしない。
- 表に縦罫は引かない。見出しの下だけ太い罫（`Th` が持っている）。

## 共通部品の使い方

| 部品 | 使いどころ |
|---|---|
| `PageContainer` | 全画面の外枠。表が横に広い事務局画面は `wide` を付ける |
| `Card` | ひとまとまりの内容。カードを入れ子にしない |
| `SectionTitle` | カード内の見出し。説明文は `note`、見出し行の右端に置く要素は `action` |
| `Tile` | 数字を見せるタイル。内訳などの小さい数字は `sub`。`tone="accent"` は1画面に1つまで |
| `Field` | 入力欄のラベル。補足は `hint` に渡す |
| `Input` / `Select` | ツールバーなどで横に並べるときは `inline`（幅いっぱいに広がらない） |
| `Badge` | 状態の表示。長いチップは `size="md"`。自前で色付き `<span>` を作らない |
| `Note` | カード内の注記の帯。`quiet` / `caution` / `alert` / `info` |
| `Alert` | 画面上部の案内。`info` / `success` / `warning` / `error` |
| `SegmentedControl` | 並べて置く切替（従業員↔事務局、勤務場所、集計の表示切替など） |

自前で `bg-white rounded-lg border ...` と書いている箇所は `Card` に、
色付きの丸い `<span>` は `Badge` に置き換える。

`Alert` は画面上部用で下余白と左罫が付く。表やタイルのすぐ下に差し込む注記は `Note` を使う。

## リンク

本文中のリンクは `text-pine hover:underline`。青は使わない（意味の色として `info` に取ってあるため）。

## やらないこと

- **文言を変えない。** 項目名・ボタン名・説明文はそのまま。見た目だけ直す。
- **操作の流れを変えない。** 入力欄の増減、並び替え、画面の分割はしない。
- **印刷用の画面（`*Print.tsx`）は触らない。** A4に収める調整と労基の様式に合わせてあるため。
- アニメーションを足さない。
